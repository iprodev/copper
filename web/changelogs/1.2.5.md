some instagram reels were saved as their cover image instead of the video. they're videos again.

- **reels as videos**: for some reels, instagram's embed page only lists the cover image. fetchr now reads the post from its own page, where the video is, and never saves a cover in place of a video. if no video can be found, you see an error instead of a picture.
