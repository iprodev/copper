---
title: "youtube works again"
date: "26 November, 2026"
---

some youtube videos, often popular ones like music videos, were downloaded as empty files. they're downloaded in full now. pornhub works in more countries, and xvideos gives simpler files.

## youtube
- **no more empty files**: for some videos, youtube only lets the app's usual way of downloading get the first minute of the file. fetchr notices that and asks for those videos the way a smart tv does, which works for the whole file. these videos take a few seconds longer to start, because youtube makes tvs wait until the ad before the video would be over.
- **a clear error instead of an empty file**: if youtube still refuses a file, you see an error instead of getting a file that's empty.
- youtube's tokens for some videos (needed for qualities above 1080p) are made by a new tool now, since the old one stopped working.

## other services
- **pornhub works in more countries**: where the site blocks its streaming files because of age verification laws, fetchr downloads the video as a single mp4 file instead, which still works there.
- **xvideos**: when the quality you asked for also exists as a single mp4 file (usually up to 480p), that file is downloaded instead of the streaming version. it's simpler, and can continue where it stopped if it's interrupted.

## other fixes
- **iphone**: tapping a tab's title in the tab bar opens the tab now, not only tapping its icon.
- the "how to save on ios" dialog links to fetchr's own siri shortcuts.
