---
title: "smoother updates for your own server"
date: "27 November, 2026"
---

for people who run fetchr on their own server: updating right after a new version is released installs that version now, not the one before it.

## updating
- **waits for the new version**: github needs a few minutes after a release to build fetchr's website and docker images. if install.sh runs before they're ready, it now waits until they are, showing how it's going, and then installs the new version. it used to install the previous version's images without saying so.
- **says what's running**: at the end, install.sh shows which version the api runs, and warns if it isn't the latest one.
- waiting can be turned off with `RELEASE_WAIT=0`. versions pinned with `FETCHR_VERSION` aren't waited for.
