title: "instant downloads in telegram"
date: "22 November, 2026"
---

the telegram bot is faster, works in more places, and stays reliable even when lots of people use it at once.

## faster
- **instant resends**: if a link was already downloaded in the same quality, the bot sends it again right away, without downloading anything. only a one-way hash of the link is kept, never the link itself.
- **queue position**: when the bot is busy, you see your place in the queue as it moves.

## in more places
- **inline mode**: type `@` and the bot's name in any chat, paste a link, and files that were downloaded before are sent right there.
- **groups**: add the bot to a group and send `/dl` with a link, or reply `/dl` to a message that has one. the bot leaves every other message alone, and its admins can turn this on or off.

## invite friends
- every user gets a personal invite link with `/invite`.
- when the bot has a daily download limit, every friend who joins with your link gives you more downloads per day.

## for whoever runs the bot
- **daily quota**: a limit on downloads per user per day (off by default), plus extra downloads for every invite.
- **vip users** without any limit.
- **a caption under every file**, with the bot's name by default. it can be changed or turned off.
- **daily backups** of the bot's database are sent to the admins, and there's a backup button in the admin panel.
- **telegram's limits are respected**: every message goes through one queue that stays below telegram's rate limits, so the bot doesn't get limited when lots of people use it. users' messages always go before broadcasts.
- **files up to 2000 mb**: the install script can set up a local bot api server, which raises telegram's limit from 50 mb.
