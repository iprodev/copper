meet fetchr, a fast and private way to save media from your favorite websites. just paste the link and get the file, no ads, trackers or paywalls.

## what's in the first release
- saving videos, audio, photos and gifs from over 20 services.
- **on-device processing**: remuxing and transcoding happen right in your browser whenever possible, so your files never leave your device.
- **remux tool**: fix incompatible media files locally, without uploading them anywhere.
- subtitles, audio covers, dubbed audio tracks, and flexible filename styles.
- support for custom processing instances and api keys.

## under the hood
- fixed session tokens that could stay valid far longer than intended.
- fixed m4a audio conversion on the server.
- fixed api key ip restrictions for ipv4 clients on dual-stack servers.
- updated all dependencies to fix known security vulnerabilities.
- added automated tests for the processing server.

fetchr is based on [cobalt](https://github.com/imputnet/cobalt) by imput. huge thanks to the cobalt team for their amazing work!
